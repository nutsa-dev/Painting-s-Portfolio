# Workspace Rules

- Group related code changes logically and create clean, meaningful Git commits only after completing a cohesive sub-task or feature (e.g., finishing a full layout section, styling a component, or completing a feature implementation). Avoid committing individual minor tweaks or single-line micro-edits.
- Automatically push clean commits to the remote GitHub repository (`main` branch) upon completing each feature or sub-task.
- Use `& "C:\Program Files\Git\cmd\git.exe"` if `git` is not in the environment PATH.
